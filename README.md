# Stellenbosch Weather

This is the source code for the website hosted at https://weather.sun.ac.za.
The site was originally built in 2008, and since then underwent a couple of major updates.

The current aim is to strip away any old unused code and features to provide a clean base to build a future-proof website.

Required features:
* Download historic weather for research, for a selected time range, in a portable format.
* Show the current weather conditions
